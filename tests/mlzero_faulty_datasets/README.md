# MLZero Faulty Synthetic Test Datasets

Five synthetic datasets for robustness/perception testing:

1. loan_approval_faulty - Finance - classification
2. patient_risk_faulty - Healthcare-style synthetic - classification
3. customer_churn_faulty - E-commerce - classification
4. house_price_faulty - Real estate - regression
5. sensor_failure_faulty - IoT - classification

Each folder contains train.csv, test.csv, and README.txt describing intentional faults.
